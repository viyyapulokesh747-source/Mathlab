# MathLab 🧮

A browser-based mathematics solver built with HTML, CSS and JavaScript.

MathLab provides a clean interface for solving common mathematics problems with
step-by-step working and a local history of recent problems.

## ✨ Features

- Basic arithmetic and percentages
- Algebra
  - Linear equations
  - Basic quadratic equations
- Geometry
  - Circles
  - Rectangles
  - Triangles
- Trigonometry
  - sin
  - cos
  - tan
- Statistics
  - Mean
  - Median
  - Mode
  - Range
- Calculus
  - Basic derivatives
  - Basic integrals
- Matrices
  - Addition
  - Multiplication
  - Determinant
- Sequences
  - Arithmetic sequences
  - Geometric sequences
- Number theory
  - Prime checking
  - Factors
  - GCD
  - LCM
  - Factorial
- Common unit conversions
- Step-by-step working
- Recent problem history using browser localStorage
- Responsive design
- No server or installation required

## 🚀 Run it

No build process is required.

Simply open `index.html` in a modern browser.

## 🧪 Example problems

```text
25 * 48
15% of 840
2*x + 5 = 17
area of circle, radius 7
sin(30)
mean of 10,20,30,40
derivative of x^2
det [[1,2],[3,4]]
arithmetic sequence 2,5,8,11, n=10
prime 97
10 km to miles
```

## 🛠️ Technology

- HTML5
- CSS3
- Vanilla JavaScript
- Browser localStorage

## 📌 Project status

**Version:** 1.0

This is a portfolio-ready V1 reference project. The current engine focuses on
common mathematical operations and intentionally does not claim to solve every
advanced mathematical problem.

Possible future versions can add:

- More advanced symbolic algebra
- Inequalities
- Complex numbers
- Limits
- Differential equations
- Graph plotting
- More matrix operations
- Natural-language word-problem solving
- A Python/SymPy backend
- Automated tests
- Cloud deployment
